# PR #63 — Visual Scene Filmstrip

The existing ChipToons Shot Director lets creators assemble two or three
original, numbered PNG animation shots, rearrange them, add a short pause
at each scene end and play a complete **silent local story reel**. PR #62
added exact cut markers and quick jumps.

This increment makes each marker immediately recognizable by its **real
first source PNG thumbnail** rather than just an identifier.

## How to use

1. In the Creative Studio Bridge on the ChipToons dashboard, choose
   **Build a multi-shot cartoon** and select valid, numbered PNGs.
2. Open **Watch your shots in order**. Each scene marker now includes the
   first original PNG frame for that shot, its shot number, filename
   prefix, exact time range and any final-frame pause.
3. Tap or click a marker to pause and jump to that shot's first real
   frame. Reorder shots using Shot Director; the thumbnail follows the
   corresponding shot. Play, Pause, Restart, seek and final holds
   continue working exactly as before.
4. Import the shots to create a new cartoon with the existing verified
   multi-scene video-export workflow.

## Privacy and compatibility

- Every preview uses the **exact original local PNG File** already
  selected by the creator. No thumbnails are generated by a remote
  service, persisted, uploaded or injected into a saved project.
- The existing `LocalFrameImage` helper creates an object URL for each
  currently displayed shot thumbnail and **revokes** it on unmount or
  source-file change. At most three shot thumbnails are shown at once,
  in addition to the existing one-frame player and per-shot previews.
- A thumbnail is decorative inside a **fully named jump button**.
  Its `aria-hidden` wrapper avoids redundant spoken image labels;
  accessible button names, current-scene state and keyboard operation
  stay unchanged.
- Light/dark high contrast and small-screen touch targets are retained.
  On desktop, real scene durations still determine filmstrip widths;
  on phones, markers are arranged as compact vertical picture cards.
- Existing source frame order, scene durations, backup schema, editors,
  classic cartoons, animated puppet rigs, voices, export codec, entire
  20-minute episode and other users' saved work are untouched.
- This remains a local **2D rendered-PNG bridge**, not a native editable
  Framefield 3D scene importer or an XR runtime.

## Verification before manual merge

- Rendered unit markup contains one first-frame thumbnail for every
  shot, without changing scene-marker names, positions or disabled state.
- Desktop, phone and tablet browser QA checks real original PNG
  decode, two distinct source files, correct thumbs after reordering,
  exact jumps, removal when clearing a file selection and cleanup
  of both temporary object URLs.
- Existing browser QA now scopes its **main reel image** separately
  from decorative filmstrip thumbnails, so Playwright selectors remain
  unambiguous without sacrificing the thumbnail UI.
- Require both Foundation/browser QA and complete 20-minute narrated

  Do not merge automatically.

## PR #64 — Write the story behind each shot

Each imported multi-shot PNG sequence can now have an optional short **scene title**, **action/lesson description**, and **written narration** prepared in Shot Director before import. These written notes follow the original shot after reordering and become normal editable scene fields in the newly created cartoon. Written narration is **not** a voice recording. See [Story Beats](FRAMEFIELD_STORY_BEATS.md).
