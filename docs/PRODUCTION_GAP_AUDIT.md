## Priority order and acceptance evidence

1. **Ship a genuinely finished pilot and then a full episode.** Record/approve original dialogue and sound, finish distinctive shots and movement for every scene, inspect decoded frames and listen across the complete movie. Report actual runtime, voices, unique visuals and artistic review separately from the engineering fixture.
2. **Make photo-based characters easier to animate.** Extend the existing manual cutout-to-puppet path with guided parts, consistent reusable looks and editable missing/occluded artwork. Verify saved character references and exported scenes after reuse. Automatic arbitrary-photo conversion or generated anime/3D looks would require a separately designed model/service or a constrained local pipeline; do not imply it is in the current app.
3. **Improve animation across custom rigs.** Add contact, balance and clipping diagnostics and creator-adjustable fixes using original sampled Stage frames; verify across walking, sitting, dancing and object interaction in decoded output. Preserve authored keyframes and source art.
4. **Raise output quality within real device limits.** #176 adds an optional 1080p WebM path for short verified output. Next, measure encoder performance, ensure practical storage/part joining for a full 1080p episode, and consider MP4 only after browser capability and decoded-file proof. Do not label a 1080p technical test a complete 1080p episode.
5. **Validate the nontechnical workflow.** Test a real creator starting from a picture, making characters/scenes/voices and recovering a project, then exporting on Windows/Android/iOS where supported. Record blocked actions and fix them with focused PRs; keep the public demo free of paid requirements.

Every future feature PR should preserve the current project and media formats where possible, include meaningful behavior tests, and use independent media decoding when picture or sound output changes. Keep PRs separate, repair failed checks on their own branches, and leave merging to the owner.
