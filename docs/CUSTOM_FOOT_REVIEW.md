# Review a custom character's foot movement

In **Edit scene → Characters & movement**, select an animated puppet and open **Review Character Feet**. Choose left or right. The studio samples up to three seconds of that character's actual Stage motion starting near the current playhead. **Review From Current Frame** moves the inspection window; a suggested frame opens the existing Stage preview. The animation, source picture, project history and exported video are never rewritten by this review.

The review works with separately parented vector or uploaded-picture foot parts outside the Workshop seating sequence. For each 24-fps sample, it projects the foot's bottom-center point through its saved joints and actor transform. It compares successive positions close to the rig's neutral-foot floor estimate and links up to five of the largest sideways intervals. The floor estimate moves with the character. It does not read the scenery floor, transparent pixels, an image's actual shoe sole, occluded artwork, camera depth, collisions or physical balance. A picture foot with transparent margins can make the point inaccurate. A clean result is not proof of contact or natural motion.

The focused browser test opens a custom picture-foot project, switches feet, jumps to a flagged real frame, and confirms the authored keys survive a project backup. The independent short-media test exports and decodes a genuine WebM of the same deliberately sliding painted foot, then measures its moving magenta pixels. This is an intentionally bad walk to verify the measurement, not a finished cartoon scene. The existing full-episode technical export remains a separate CI gate; a completed 15–20-minute children's episode still requires original art, voices, editing and artistic review.
